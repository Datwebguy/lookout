How it works

Five real signals. One autonomous decision.

  1. 1

    Now

    Real hyperlocal temperature at this exact worksite — area-weighted across every FortyGuard tile the site touches, not a nearest-tile guess.

  2. 2

    Ahead

    FortyGuard has no live forecast — we verified that empirically — so Lookout projects the next few hours from real climatology plus today's real anomaly.

  3. 3

    Baseline

    What's actually normal for this site, this hour, computed from real multi-year history — not a citywide average.

  4. 4

    Duration

    How many hours this site has run past a danger threshold. At site scale, peak temperature is nearly flat — duration is what actually separates a dangerous day.

  5. 5

    The worker

    Role, shift hours, and risk flags — so identical weather can produce a different decision for a different person.
